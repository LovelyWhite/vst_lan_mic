01 特性

为稳定传输而生

从发现设备到音频流水线，每个环节都为「不卡顿」做了针对性设计。

零配置发现

局域网广播自动发现 LAN MIC 设备，无需固定 IP 或手动填写地址；多网卡环境下逐接口绑定，规避 VPN 与虚拟网卡干扰。

采样率自适应

网络与 USB 固定 48 kHz，插件自动转换 DAW 工程采样率，44.1 / 48 / 88.2 / 96 kHz 工程即插即用。

双向真立体声

上下行都保留左右声道分离，Opus 192 kbps 立体声编码；两个方向丢包均由解码器智能补帧掩盖。

无锁实时流水线

独立网络线程 + 原子同步有界队列，电脑端无锁；短丢包平滑补偿、欠载淡出、延迟积累自动裁剪。

智能省电

设备在 USB 音频空闲时自动休眠省电，音频流恢复瞬间唤醒，待机不影响使用。

一物两用，全平台兼容

标准 UAC2 USB 音频：插手机即无线麦克风与监听耳麦，插电脑、平板也能直接作为外置声卡使用，Windows / macOS / Android / iOS 全平台即插即用。

02 插件

两个插件，两条链路

深色界面与 DAW 融为一体。设备、增益、启停与连接统计一目了然。

LAN MIC Send.vst3SEND

LAN MIC Send

插入要送给手机的音轨或总线。始终保留本地原声，Network gain 只调整发送到手机的音量，旁路不影响监听。

DAW → net → Lan mic

LAN MIC Return

插入独立监听音轨，用手机回传声音替换输入。无需先打开编辑器，工程加载即自动启动接收租约。

Lan mic playback → net → DAW
03 快速开始

四步跑通全链路

连接硬件 → 设备配网 → 安装插件 → DAW 路由。全程约 10 分钟。

STEP 1

连接硬件与网络

  • 设备自带 Type-C 公头，直接插入手机即可；供电不足时使用有源 USB Hub。
  • 设备与电脑接入同一局域网；设备使用 2.4 GHz Wi-Fi，请关闭路由器 AP 客户端隔离。
  • 在手机上选择 LAN MIC 设备作为外置 USB 麦克风/耳麦。
STEP 2

为设备配网

  • 首次使用时，设备会创建开放热点 LAN MIC-<设备编号>，手机连接后自动弹出配网页（或访问 http://192.168.4.1）。
  • 选择 2.4 GHz Wi-Fi 并输入密码，凭据保存在设备中，之后开机自动连接。
  • 需要更换网络时，长按设备按键约 3 秒清除凭据，重新进入配网。
STEP 3

安装插件

使用下方安装包，双击向导式安装到 DAW 插件目录，启动 DAW 重新扫描插件即可看到 LAN MIC Send 和 LAN MIC Return。

STEP 4

DAW 路由与验证

  • 在要发给手机的音轨/总线上插入 LAN MIC Send。
  • 在独立、启用监听且持续处理的音轨/总线上插入 LAN MIC Return。
  • 两个插件选择同一台设备；多设备环境请显式指定。
  • 在目标手机 App 中授权使用外置 USB 麦克风/耳麦。
  • 插件状态栏显示 Connected | LAN MIC 即链路就绪。
  • 不要把 Return 的返回总线再送进 Send，避免环回啸叫。
延迟提示：初始配置偏向稳定，适合直播推流、录音与监听场景，不建议替代要求极低延迟的有线现场监听。实际端到端延迟需按环境实测。

06 兼容性

兼容性与注意事项

开播之前，花一分钟确认这些边界条件。

全平台兼容设备是一枚标准 UAC2 USB 声卡。插进手机就是无线麦克风与耳麦：Android 直接插 USB-C，iPhone 的 USB-C 口同样直插，Lightning 口需接相机转接器。插进 Windows / macOS / Linux 电脑，则直接作为外置声卡使用。
应用采纳系统枚举成功不代表所有通话/直播 App 都会采用该输入，部分应用可能强制使用内置麦克风或单声道。
网络安全仅限可信局域网使用，不要映射端口到公网。
网络环境关闭 AP 客户端隔离；VPN、多网卡、访客网络可能影响设备发现。
DAW 导出离线导出时网络音频自动禁用；需要导出手机声音请先实时录制成音频文件。
