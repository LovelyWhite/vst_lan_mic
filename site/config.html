维护

只清除设备保存的 WiFi 名称和密码，设备名称与音频通道不受影响；重启后设备重新进入配网。设备连不上时用下方「更新设备固件」恢复

更新设备固件

连接设备后自动检查版本是否有新固件

  1. 把设备从电脑上拔下来
  2. 按住设备上的按钮不放
  3. 保持按住，把设备重新插入电脑
  4. 点下方「开始更新」，在端口列表里选 USB JTAG/serial debug unit

更新会覆盖设备上的程序；网页驱动连不上或固件损坏时也可按上面步骤更新
